# PizzBurg: правила работы агента

Этот файл обязателен к прочтению перед любой работой в репозитории.

## С чего начинать

1. Прочитать `docs/INDEX.md`.
2. Прочитать `docs/HANDOFF.md`, `docs/DECISIONS.md` и `docs/ROADMAP.md`.
3. Для текущей задачи прочитать профильный документ из `docs/`.
4. До изменений выполнить `git status --short` и просмотреть существующий diff. Не перезаписывать чужие незавершённые изменения.

`docs/PROJECT.md` — подробный исторический журнал. Он полезен для контекста, но текущий статус и приоритеты определяются документами выше.

## Текущий приоритет

Безопасно подготовить перенос клиентской базы из FoodPicasso: около 15 тысяч профилей, телефоны, балансы и доступные метаданные. Инструкция и известные API описаны в `docs/FOODPICASSO_MIGRATION.md`.

## Неприкосновенные ограничения

- Старое арендованное приложение FoodPicasso остаётся основным до полного прохождения функциональных, финансовых и эксплуатационных проверок нового приложения.
- Не отключать и не изменять старое приложение, боевой Poster, Railway production или реальные платежи без явного разрешения пользователя.
- Любой тест отправки заказов в Poster по умолчанию проводить с `POSTER_DRY_RUN=1`. Боевой тест — только после прямого согласования.
- Не импортировать выгруженную клиентскую базу в рабочую БД без отдельного подтверждения. Сначала экспорт, проверка, отчёт и dry-run импорта.
- Не коммитить cookies, токены, private keys, сертификаты, `.env`, Firebase service account JSON и другие секреты.
- Не удалять и не перезаписывать незнакомые изменения в dirty worktree.
- Не хардкодить PizzBurg: архитектура должна оставаться пригодной для нескольких арендаторов/заведений.

## Как вести работу

- Общаться с пользователем на русском языке и давать конкретные действия.
- Проверять изменения тестами соразмерно риску.
- После значимого этапа обновлять `docs/HANDOFF.md`, а при изменении продукта — также `docs/DECISIONS.md` и `docs/ROADMAP.md`.
- В конце фиксировать: что сделано, что проверено, что осталось, какие действия нужны от пользователя.
