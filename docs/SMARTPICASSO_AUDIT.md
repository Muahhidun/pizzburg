разделом. Для каждого пункта: **нужно ли нам** и **приоритет**.

Легенда приоритетов:
- **P1** — нужно до запуска (без этого хуже, чем сейчас)

- **P3** — приятно иметь, необязательно
- **✖** — не берём (с обоснованием)

Статус: ✅ уже сделано у нас · ⏳ запланировано · 🆕 новое, этого в
нашем плане не было.

## 6. Маркетинг

### 6.1 Акции — здесь их главное преимущество

**18 типов акций**: 2+1, 3+1, 1+1=3, 1+1 бесплатно, 1+1 со скидкой,
n+подарок, сумма+подарок, сумма+подарок на выбор, сумма+скидка,
сумма+грейд, комбинированная, блюда со скидкой, 1+n=фикс цена,
1+1 фикс цена, наименьшая фикс цена, дорогая фикс цена, баллы,
промо-продукт.

**17 настроек-флагов у каждой акции**: только один раз в день; только
на первый заказ; применять автоматически; только один раз каждому;
не учитывать сторонние заказы; только навынос / только на доставку /
только в заведении; только через приложение / сайт / Posterix;
требовать авторизацию; не увеличивать установленную скидку;
не действует при заказе блюд с зачёркнутой ценой; установить
бесплатную доставку; отображать только когда акция активна;
только в определённых зонах; только в определённых ресторанах.

| Что | Нам | Приоритет |
|---|---|---|
| Наш движок: «N из категории → подарок» | ✅ покрывает 2+1, 4+1 | — |

| **Тип «скидка %/₸ на позицию или заказ»** | 🆕 базовый, у нас его нет | **P1** |

| Флаг «установить бесплатную доставку» | 🆕 удобный маркетинговый ход | P2 |

### 7.3 Предзаказы (проработано у них детально)
- Интервал времени для клиента («выбранное время +15 мин») — 🆕 **P1**
- Как скоро можно оформить предзаказ (доставка через 90 мин, навынос через 20 мин) — 🆕 **P1**
- Интервал между предзаказами (15 мин) — 🆕 P2
- Когда отключать «Как можно быстрее» (за 3 мин до закрытия) — 🆕 **P1**

Без этих настроек предзаказы работать нормально не будут — это
готовая, продуманная модель, забираем целиком.

### 7.4 Адреса и зоны доставки

- У каждой зоны: **своё меню**, время доставки, мин. заказ, стоимость, бесплатно от — 🆕 P2 (пригодится для SaaS и второго города)

## Итог: что забрать в первую очередь (P1)

1. **Карточка товара**: свои фото, вес, состав, метки («хит», «острое»).
2. **Акции**: типы «сумма+подарок» и «скидка %/₸», флаги ограничений
   (только доставка/самовывоз, первый заказ, один раз каждому,
   требовать авторизацию), баннеры акций в приложении.
3. **Баллы**: журнал транзакций, ручное начисление/списание, перенос
   балансов при миграции.
4. **Пуши**: сегменты клиентов + действие по клику (блюдо/раздел/акция).
5. **Настройки оплаты**: уточнять сдачу, отмена заказа клиентом за N минут.
6. **Предзаказы**: вся их модель интервалов целиком.
7. **Время работы**: профили расписаний (Рамадан!).
8. **Зоны**: рубильник «только самовывоз».
9. **Заказы**: причина отмены (справочник + отчёт).
10. **Юридическая информация**: оферта и политика — иначе не пройдём
    ревью сторов.

Это добавляет к плану примерно 2–3 недели работы, но именно эти вещи
отличают «работает» от «работает как у взрослых».
