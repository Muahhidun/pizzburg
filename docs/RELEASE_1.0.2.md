# Выпуск 1.0.2 (8): корзина, предзаказ, мягкое обновление

Решение Дома 28.11.2026. Источник остальных полей карточки — `docs/APP_STORE.md`,
`docs/GOOGLE_PLAY.md`, `docs/RELEASE_1.0.1.md`.

## Что поменялось

- **Доставка / Самовывоз — в корзине, первым блоком.** Переключатель с главной
  убран: он не доходил до корзины, и клиенты на самовывоз видели +700 ₸.
  Первый заказ — ничего не выбрано, доставка не считается, кнопка просит
  выбрать. Выбор запоминается (`OrderMode`, SharedPreferences). Шапка главной
  только показывает «Доставим на …» / «Заберёте из …».
- **Оформление:** строка «Доставка · Сменить на самовывоз» вместо второго
  переключателя.
- **Когда:** «Как можно скорее» (по умолчанию) или «Предзаказ» → «Сегодня, сб 28
  ноября» / «Завтра, вс 29 ноября» (день не подставляется сам, если вариантов
  два) → время списком снизу. Над кнопкой «Предзаказ на завтра, вс 29 ноября,
  11:45–12:00», на кнопке «На завтра 11:45». Без дня и времени заказ не уходит.
- **Баллы:** светлая строка «Баллы: 1 480 · можно списать 975 ₸» с
  переключателем; «Списать часть» раскрывает ползунок.
- **Сервер:** `preorder.maxDaysAhead` — календарные дни (0 — только сегодня,
  1 — сегодня и завтра, по умолчанию 1). Слоты отдают `date`, ответ — `today`.
  Кассирам: «ПРЕДЗАКАЗ — НА ЗАВТРА, 12:00 (29.11)».
- **Устаревшие версии:** приложение шлёт `X-App-Version` и `X-App-Platform`.
  Заказ из версии ниже минимальной (Админка → Операции → минимальная версия)
  получает 426 с текстом «Обновите PizzBurg в App Store или Google Play».
  Без заголовка (1.0.0 и 1.0.1) версия считается самой старой. Сайт
  (`X-Client: web`) не трогаем.

## Обновление: мягко, а не силой (решение Дома 28.11)

- **Рекомендуемая версия** (Админка → Операции → «Обновление приложения»,
  `appUpdate.recIos/recAndroid`, в `/app/:slug/config` — `recommendedVersion`).
  Ниже неё приложение (с 1.0.2) показывает снизу окно «Вышла новая версия»
  с «Обновить» / «Позже», только на главном экране, не чаще раза в 2 дня
  (`UpdatePrompt`). Заказывать можно без обновления.
- **Обязательная версия** — только если старая версия сломалась: экран без
  выхода (с 1.0.1) и отказ в заказе для 1.0.0 (`app-version-gate`).
- 1.0.0 и 1.0.1 мягкого окна не умеют — для них один push «Вышло обновление».
- После выхода 1.0.2 обязательную не ставим. Когда выйдет 1.0.3 —
  рекомендуемая `1.0.3`.
