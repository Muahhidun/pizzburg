# Карта документации PizzBurg

Актуально на 12 августа 2026 года.

## Порядок приоритета

Если документы расходятся, использовать такой порядок:

1. Последнее явное указание пользователя.
2. `DECISIONS.md` — принятые продуктовые и технические решения.
3. `HANDOFF.md` — актуальный статус и ближайшая задача.
4. `ROADMAP.md` — последовательность будущих этапов.
5. Профильные документы подсистем.
6. `PROJECT.md` — исторический журнал, в котором могут оставаться устаревшие промежуточные записи.

## Обязательные документы

| Файл | Назначение |
|---|---|
| `../AGENTS.md` | Правила работы нового агента и ограничения безопасности |
| `HANDOFF.md` | Где остановились, что подтверждено и что делать сейчас |
| `DECISIONS.md` | Канонические решения по продукту, лояльности, платежам и миграции |
| `ROADMAP.md` | Этапы до безопасной замены арендованного приложения |
| `NEW_CHAT_PROMPT.md` | Готовый текст для начала нового чата |

## Быстрый вход нового агента

Новый агент не должен заново восстанавливать историю из переписки. Ему достаточно прочитать обязательные документы, затем профильный документ текущего этапа и проверить рабочее дерево Git.
