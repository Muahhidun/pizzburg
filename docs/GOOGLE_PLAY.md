## 2. Русская карточка

### Название — до 30 знаков

```
PizzBurg — доставка еды
```

### Краткое описание — до 80 знаков

```
Пицца, бургеры, суши и донеры с доставкой и самовывозом в Экибастузе
```

### Полное описание

```
PizzBurg — доставка еды в Экибастузе. Пиццы, бургеры, суши и роллы,
донеры, крылышки, сэндвичи, хот-доги и напитки. Готовим сами, привозим
сами.

ЗАКАЗ ЗА ПОЛМИНУТЫ
Меню с фотографиями и составом каждого блюда. Любимое сохраняется в
избранном, прошлый заказ повторяется одним нажатием.

ВИДНО, ЧТО ПРОИСХОДИТ
После оформления открывается экран заказа: приняли, готовим, доставлен.
Уведомления приходят сами, обновлять ничего не нужно.

МИНУТА НА ОТМЕНУ
Сразу после оформления заказ ещё можно отменить без последствий — на
экране идёт обратный отсчёт, и до его конца заведение о заказе не знает.

БАЛЛЫ ЗА КАЖДЫЙ ЗАКАЗ
Возвращаем баллами от 3 до 6% — процент растёт вместе с суммой заказов за
всё время. Один балл равен одному тенге, ими можно оплатить до 30%
стоимости следующего заказа.

ЕСЛИ ЧЕГО-ТО НЕ ОКАЖЕТСЯ
Скажем сразу и спросим, везти остальное или отменить. Решаете вы, а не мы.

ЧЕСТНОЕ ВРЕМЯ
Когда кухня загружена, предупредим об этом до оформления, а не после.

ДОСТАВКА И САМОВЫВОЗ
Привезём по адресу или отдадим в заведении: Экибастуз, Ауэзова 47Б,
ТРЦ «MaxiMall», 3 этаж. Можно заказать на конкретное время.

ОПЛАТА
Наличными или картой при получении.

ҚАЗАҚША ДА
Приложение работает на казахском языке — переключается в профиле.

Режим работы: ежедневно с 10:00 до 21:20.
```

## 7. Data safety

Ответы должны описывать не только Flutter-клиент, но и backend PizzBurg.
Реклама и передача данных сторонним рекламным сетям отсутствуют.

| Категория Google | Данные | Собираются | Передаются третьим лицам | Обязательность | Назначение |
|---|---|---|---|---|---|
| Personal info | имя | да | нет | необязательно | функции приложения, управление аккаунтом |
| Personal info | идентификаторы пользователей | да | нет | необязательно | функции приложения, управление аккаунтом |
| Personal info | адрес доставки | да | нет | необязательно | функции приложения |
| Personal info | номер телефона | да | нет | необязательно | функции приложения, управление аккаунтом |
| Financial info | история покупок | да | нет | необязательно | функции приложения, управление аккаунтом |
| Messages | другие сообщения в приложении | да | нет | необязательно | функции приложения |
| App activity | действия в приложении | да | нет | обязательно | аналитика |
| App activity | история поиска в приложении | да | нет | необязательно | аналитика |
| App activity | другой контент, созданный пользователями | да | нет | необязательно | функции приложения |
| Device or other IDs | push-токен и случайный ID установки | да | нет | обязательно | функции приложения, аналитика |

Дополнительные ответы:

- Data is encrypted in transit: **Yes** — production работает по HTTPS.
- Users can request that data is deleted: **Yes** — в приложении есть
  «Профиль → Настройки приложения → Удалить аккаунт».
- Account creation method: номер телефона и код подтверждения.
- Запрос удаления аккаунта: `https://api.pizzburg.kz/legal/pizzburg/support/page`.
- Отдельный запрос частичного удаления данных без удаления аккаунта: **No**.
- Просмотр каталога доступен без входа. Поведенческие события и случайный ID
  установки собираются автоматически; данные профиля, заказа и сообщения —
  только когда пользователь использует соответствующие функции.
- Ephemeral processing: **No** для перечисленных данных.

Перед отправкой анкеты ещё раз сверить формулировки с production-сборкой и
актуальным SDK Firebase. Firebase используется как обработчик для доставки
push, а не для рекламы.
