## App Review Information: новые Notes

Логин и код не меняются: `+7 718 755 60 84`, `875000`
(вход проверен на production 18.11).

```
Вход в приложение — по номеру телефона и коду из SMS.
Для проверки используйте тестовый номер: +7 718 755 60 84
Код подтверждения: 875000 (постоянный, SMS на этот номер не отправляется)

Меню, поиск и карточки блюд доступны без входа.
Вход требуется только для оформления заказа.

Оплата. Приложение продаёт еду с доставкой и самовывозом — физические
товары, которые потребляются вне приложения, поэтому встроенные покупки
Apple не используются (Guideline 3.1.3(e)). Кроме наличных и карты при
получении, доступна оплата через Kaspi.kz: после оформления приложение
открывает Kaspi.kz, где клиент подтверждает платёж. Для этого нужен счёт
в Kaspi Bank (Казахстан). Неоплаченный заказ отменяется автоматически
и на кухню не попадает. Для проверки выберите «Наличными» — заказ можно
отменить на экране заказа в течение минуты.

Новое в 1.0.1: оплата Kaspi, переписка с заведением на экране заказа,
пояснение перед запросом уведомлений.

Удаление аккаунта: Профиль → Настройки приложения → Удалить аккаунт.

Приложение работает в одном городе Казахстана (Экибастуз).
```
