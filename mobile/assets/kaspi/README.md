# Официальные материалы Kaspi

В эту папку добавляются только файлы, которые передал и согласовал Kaspi.
Самодельные логотипы и кнопки запрещены требованиями UI/UX.

Ожидаемый файл для мобильной оплаты: `pay-button-red.png` (или замена кода
на официальный SVG/готовый компонент). До его получения сборка создаётся
без `--dart-define=KASPI_BRAND_ASSETS_READY=true`, поэтому Kaspi не
показывается клиентам даже при ошибочной серверной настройке.
