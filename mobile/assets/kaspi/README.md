# Официальные материалы Kaspi

Сюда кладём только файлы, полученные от Kaspi. Самодельные логотипы и
кнопки запрещены гайдом «Правила использования элементов оплаты с Kaspi.kz».

Источник: Figma Kaspi «Оплата с Kaspi.kz» (pNQjZoaE1v2Ud2cpqtU4sq),
блок «Кнопки и логотипы», экспорт SVG 13.11.2026, текст переведён в контуры.

- `pay-button-red.svg` — Button / Logo «Оплатить с Kaspi.kz», 343×52.
  Kaspi требует высоту не меньше 48 dp и свободную зону не меньше 8 dp вокруг.
- `logo-kaspi.svg` — полный логотип, 112×28 (минимальная длина по гайду).
- `logo-kaspi-circle.svg`, `logo-kaspi-card.svg` — сокращённые логотипы,
  когда название написано текстом.
- `logo-gold.svg`, `logo-red.svg` — способы оплаты Gold и Red, 36×28.

Пока сборка не создана с `--dart-define=KASPI_BRAND_ASSETS_READY=true`,
Kaspi клиентам не показывается, даже если сервер случайно его включит.
